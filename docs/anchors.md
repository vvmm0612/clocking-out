# 锚点表（灰盒参照）

由 `Assets/Editor/GreyboxExport.cs` 生成（`-executeMethod GreyboxExport.Run`），**不要手改**。改了 `StageLayouts.cs` 后重新运行。
每关的灰盒 OBJ 在 `docs/greybox/<levelId>.obj`，导入 Blender 当作比例和位置参照（规则见 `docs/art-brief.md` 第 2 节）。

- **原点**：锚点在世界坐标里的位置（Unity 坐标，Y 向上，镜头从 -Z 方向看向 +Z）。替换模型的原点会和它对齐，不做任何缩放。
- **灰盒包围盒**：该锚点灰盒外观的尺寸 宽×高×深（X×Y×Z），以及包围盒中心相对原点的偏移。模型大致占这块空间即可。
- **spin / toggle / light**：该锚点有持续旋转、开关（或铰链）、点亮行为；模型里对应子节点命名 `spin`、`toggle`、`light`，没有就作用于整个模型。
- **类型**：地点 = 表单 Place 栏的选项（主角站在原点上）；NPC = 人物（按班次被摆到不同地点）；其他 = 物件。
